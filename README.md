## Project Overview

The Modern Todo List is a React-based web application designed to help users organize daily tasks efficiently. It allows users to add new tasks, edit them, mark them as completed, and remove them when no longer needed. The app provides a clean and user-friendly interface for managing both active and completed tasks.

This project focuses on building a simple yet effective task management system using React.js and Bootstrap, helping users stay productive and organized.

## Project Objectives

- Create a responsive todo list application.
- Allow users to add new tasks easily.
- Enable editing of existing tasks.
- Provide task completion tracking.
- Separate active tasks from completed tasks.
- Deliver a clean and interactive user interface.

## Features

- Add new tasks to the list.
- Edit tasks inline.
- Delete unwanted tasks.
- Mark tasks as completed.
- View completed tasks separately.
- Responsive design for different screen sizes.
- Modern UI using Bootstrap styling.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm
- Visual Studio Code
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/ganeshathmakuri/modern_todo_list.git
```

### Step 2: Navigate to the Project Folder

```bash
cd modern_todo_list
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Run the Application

```bash
npm start
```

This will start the React development server and open the application in the browser.

## 🧩 Application Workflow

The application allows users to:

1. Type a task in the input field.
2. Add it to the todo list.
3. Edit the task when needed.
4. Mark the task as complete.
5. Remove the task from the list.
6. Review completed tasks in a separate section.
